## 2. Implementation Tasks

### Task 2.1: Schema Definition (1.5h) ✅ COMPLETED
**Goal**: Create the type-safe schema definition in Convex.
- **File**: `convex/schema.ts`
- **Reference**: `docs/guides/convex-database-schema.md`
- **Steps**:
    1. Define `users` table (profiles, usage limits)
    2. Define `workspaces` & `organizations` (tenancy root)
    3. Define `agents`, `roles`, `personas`, `frameworks` (AI configuration)
    4. Define `sessions`, `messages`, `threads` (Chat history)
    5. Define `artifacts`, `artifactVersions` (Content management)
    6. Define `invitations`, `apiKeys` (Access control)

### Task 2.2: Core Mutations & Queries (1.5h)
**Goal**: specific API endpoints for frontend interaction.
- **Files**: `convex/users.ts`, `convex/agents.ts`, `convex/sessions.ts`
- **Steps**:
    1. `storeUser`: Upsert user from Clerk auth data
    2. `createAgent`, `updateAgent`, `deleteAgent`: CRUD for agents
    3. `createSession`, `addMessage`: Chat operations
    4. `getAgentLibrary`: Fetch available roles/personas/frameworks

### Task 2.3: Data Seeding (1h)
**Goal**: Migrate static TypeScript constants to Database records.
- **Files**: `convex/seed.ts`
- **Source Data**: 
    - `lib/agent-config/roles.ts` -> `roles` table
    - `lib/agent-config/personas.ts` -> `personas` table
    - `lib/agent-config/frameworks.ts` -> `frameworks` table
- **Steps**:
    1. Create internal mutation `seedStaticData`
    2. Iterate through static lists and upsert by unique key (e.g., `slug` or `name`)
    3. Ensure no duplicates are created on re-runs

### Task 2.4: Frontend Type Refactoring (1.5h)
**Goal**: Align frontend interfaces with backend schema.
- **Files**: `lib/types.ts`, `lib/agent-config/types.ts`
- **Steps**:
    1. Replace `string` IDs with `Id<"tableName">` from `_generated/dataModel`
    2. Update `Agent` interface to include `_id`, `organizationId`
    3. Update `ChatMessage` to match backend `Message` structure

## 5. Troubleshooting Guide

### "Schema mismatch" errors
- **Cause**: Local `schema.ts` differs from cloud.
- **Fix**: Run `npx convex dev` to push changes or `npx convex codegen` to update types.

### "Authentication missing"
- **Cause**: Clerk token not passed to mutations.
- **Fix**: Ensure `ConvexProviderWithClerk` is wrapping the app in `providers.tsx`.

### "Duplicate key error" during seed
- **Cause**: Seed script running multiple times without idempotency.
- **Fix**: Use `db.query(...).withIndex(...)` to check existence before inserting.
