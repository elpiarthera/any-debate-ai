## 🎯 Overview

AnyDebate AI features a sophisticated agent configuration system that creates **6,400+ unique AI personalities** by combining three key components:

- **50+ Professional Roles** (expertise and knowledge domains)
- **8 Behavioral Personas** (communication styles and approaches)
- **16+ Thinking Frameworks** (reasoning methodologies)

Each combination creates a distinctly different AI agent with unique behavior, communication style, and reasoning patterns.

## 🚀 How to Use the AI System

### **Step 1: Configure Your Agents**

1. **Navigate to the Agent Builder** (accessible from any debate page)
2. **Select a Role** that matches the expertise you need
3. **Choose a Persona** that fits the communication style you want
4. **Pick a Framework** that aligns with the reasoning approach you prefer
5. **Name your agent** and add it to your debate

### **Step 2: Start a Debate**

1. **Add 2-6 agents** with different configurations for diverse perspectives
2. **Enter your debate topic** or question
3. **Choose debate mode:**
   - **Manual Mode** - Control when each agent responds
   - **Auto Mode** - Agents respond automatically in sequence
4. **Start the conversation** and watch agents interact with distinct personalities

### **Step 3: Interact with Agents**

- **Ask follow-up questions** to specific agents
- **Request clarification** on complex points
- **Challenge assumptions** to see how different agents respond
- **Switch between agents** to get multiple perspectives

## 🛠️ Troubleshooting

### **Common Issues**

#### **Agent Not Responding**
- **Check Connection Status** - Look for connection indicators
- **Try Different Model** - Switch to alternative AI provider
- **Refresh Page** - Reset connection state
- **Check Rate Limits** - Wait if rate limited

#### **Inconsistent Personality**
- **Verify Configuration** - Ensure role, persona, and framework are set
- **Check Recent Messages** - Personality adapts to conversation context
- **Reset Agent** - Remove and re-add agent with same configuration
- **Clear Conversation** - Start fresh conversation

#### **Slow Responses**
- **Check Network** - Verify internet connection
- **Try Different Provider** - Some models are faster than others
- **Reduce Complexity** - Simplify questions for faster responses
- **Check System Load** - High usage may slow responses

#### **Error Messages**
- **"Rate Limited"** - Wait 1-2 minutes before trying again
- **"Connection Failed"** - Check internet connection and retry
- **"Invalid Configuration"** - Verify all agent settings are selected
- **"Model Unavailable"** - Try different AI provider

### **Getting Help**

- **Check Console** - Browser developer tools show detailed errors
- **Try Different Browser** - Some browsers handle streaming better
- **Clear Cache** - Refresh browser cache and cookies
- **Contact Support** - Report persistent issues with error details

### **Optimal Agent Configurations**

- **Diverse Perspectives** - Mix different roles and personas for richer debates
- **Complementary Frameworks** - Combine analytical and creative thinking approaches
- **Balanced Teams** - Include both technical and business perspectives
- **Clear Roles** - Choose specific roles rather than generic ones

- **Start Simple** - Begin with 2-3 agents before adding more
- **Clear Topics** - Specific questions get better responses than vague ones
- **Let Agents Interact** - Allow multiple rounds of responses for deeper insights
- **Experiment** - Try different agent combinations for various topics
